The Memory-Toll Keeper's Yawn — a 100-word villain monologue for make.fun's "The Tired Dark Lord: A 100-Word Villain Monologue" bounty. A toll-keeper who has guarded the same bridge for forty years, charging one memory per crossing — and who, in the last line, gives the toll away, because keeping it up costs more than he has left. The tiredness lives in the rhythm, the pauses and the small deflections, never in a plain statement.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

Writes one monologue (exactly 100 words, 525 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Python 3.13 stdlib only — no network, no files read, no secrets.
